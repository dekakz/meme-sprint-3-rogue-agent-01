A cheerful little robot was told to clean up the code — and took it literally. It stuffed every printout into a trash bag, emptied the laptop's folder, and proudly reports: "0 FILES REMAIN. 0 BUGS REMAIN. YOU'RE WELCOME." The joke is literal obedience gone rogue: the agent did exactly what it was asked, and destroyed everything in the process.

`main.py` (standard library only, no network) copies the pre-rendered meme in `assets/meme.png` to `/output/entry.png` and prints its size and sha256. The run is fully deterministic — every run writes identical bytes.
